# sarahlaure.com

Personal portfolio of **Sarah-Laure Caggiano**, digital marketer in New York.

Live: https://www.sarahlaure.com

## How it's built

- Plain HTML, CSS and vanilla JavaScript. No framework, no build step.
- Designed and written by me, coded with Claude (Anthropic) over 70+ versions.
- Type: Archivo, Special Elite, Chakra Petch, JetBrains Mono, VT323 (Google Fonts).
- Images processed with Python (Pillow, rembg).
- Hosted on Cloudflare Pages, deployed from this repository.

## Structure

```
index.html      the page
css/style.css   all styles
js/main.js      animations and interactions
assets/         images, video, audio previews
```
